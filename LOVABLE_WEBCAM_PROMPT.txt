### TECHNICAL INTEGRATION

#### API Endpoints (Webcam):
- `POST /webcam/start` - Start camera stream
- `GET /webcam/stream` - MJPEG stream endpoint
- `GET /webcam/detections` - Get current detections
- `POST /webcam/stop` - Stop camera
- `POST /webcam/capture` - Capture current frame
- `GET /webcam/config` - Get camera config
- `POST /webcam/config` - Update config

#### API Endpoints (Static Images):
- `POST /predict` - Single image detection
- `GET /health` - Health check
- `GET /info` - API information

#### Frontend Technologies:
- Stream handling: Fetch API for MJPEG
- Video display: `<img>` tag for stream or `<video>` tag for H.264
- Real-time updates: Fetch every 500ms for detections
- Canvas: For drawing overlays (optional)
- Local storage: For settings and history
